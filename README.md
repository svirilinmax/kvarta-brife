# Кварта — лендинг обжарки кофе

Лендинг для мастерской обжарки кофе «Кварта» (Минск) с формой заявки.

## Стек

- **Backend:** FastAPI + SQLAlchemy (async) + Supabase (PostgreSQL)
- **Frontend:** статика (HTML/CSS/JS), без фреймворков
- **Хостинг:** Vercel (serverless functions + CDN для статики)
- **Миграции:** Alembic
- **Тесты:** pytest + httpx + aiosqlite
